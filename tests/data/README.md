# Test fixtures

Self-contained data for the test suite (no external `/workspace/...` paths). Regenerate with
`python tests/data/generate_fixtures.py` (see that script for exact filter logic).

## Provenance

**Source REMIND run**: `SSP2-EU21-PkBudg1000-AMT_2026-07-11_01.03.42`

**Filter applied to every REMIND-derived fixture**: years `2090`/`2100`, regions `DEU` (Germany,
single-country), `EWN` (Austria+Belgium+Luxembourg+Netherlands) and `CHA` (China+Hong Kong+Macao+
Taiwan, both multi-country — chosen so downscaling logic gets exercised across a real
region→country split, not just single-country no-ops), and only the GDX symbols / mif variables
the package actually reads (per `remind_symbols_gdx.yaml`/`remind_symbols_mif.yaml`).
